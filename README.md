# AE007 — αυτόνομη έκδοση (Unit Linked + ασφαλιστικός πράκτορας)

Αυτός ο φάκελος είναι σχεδιασμένος ώστε να **λειτουργεί χωρίς** την υπόλοιπη δομή του repo **Axia Xronou**: αρκεί περιεχόμενο μέσα στο `AE007/` και τοπικός διακομιστής ή **GitHub Pages** (ως ρίζα site).

## Τι περιλαμβάνει

| Στοιχείο | Ρόλος |
|-----------|--------|
| `index.html` | Εφαρμογή — παράγεται από το ριζικό `index.html` του monorepo |
| `questions_bank.json` | Τράπεζα Unit Linked (**αντιγράφεται στο build από τη ρίζα**) |
| `insurance_agent_yli/` | Ύλη & λίστες πράκτορα (manifest + bundled JSON αν υπάρχει) |
| `theoria/` | Θεωρία ανά κεφάλαιο για το κουμπί **«Θεωρία Ενότητας»** στο quiz UL (**αντιγράφεται στο build**) |

**Δεν** συμπεριλαμβάνεται (εξορισμού σε αυτή την έκδοση):

- τράπεζα θεμάτων κεφαλαιαγοράς (`yli/`), μεσίτης (`insurance_yli/`)
- **`analytikes-lyseis-lab`** — στο AE007 **δεν** εμφανίζεται το πλαίσιο «Εργαστήριο αναλυτικών λύσεων» δίπλα στο Unit Linked (αφαιρείται κατά την παραγωγή)

## Παραγωγή / συγχρονισμός (από ρίζα repo AxiaXronou)

Πηγή αλήθειας για UI παραμένει το **`index.html` στη ρίζα του monorepo**. Μετά από αλλαγές εκεί που πρέπει να φανούν στο AE007:

```bash
python3 AE007/build_simplified.py
```

Το script:

1. Ξαναγράφει το `AE007/index.html` από το ριζικό `index.html` (με τις ήδη υπάρχουσες αφαιρέσεις μεσίτη / κεφαλαιαγοράς κ.λπ.)
2. Αφαιρεί το σύνδεσμο **`quizAnalytikesLyseisLabLink`** (εργαστήριο αναλυτικών λύσεων) και το σχετικό **CSS** `quiz-lab-link-card`
3. Αφαιρεί τον κώδικα υπολοίπου **`quizMesCheckedFooter`** (μεσίτης), μη διαθέσιμος στην έκδοση AE007
4. Αντιγράφει **`questions_bank.json`** και τον φάκελο **`theoria/`** από τη ρίζα μέσα στο `AE007/`

Δεν επεξεργάζεστε μόνιμα για δομή και κύριες οθόνες μόνο το `AE007/index.html` χωρίς να τρέξετε build — στο επόμενο script θα αντικατασταθεί.

## Σταθερότητα / αποθήκευση προόδου

Η εφαρμογή κρατά προσωρινά την τρέχουσα πρόοδο του quiz Unit Linked στο browser `localStorage`, ώστε αν γίνει refresh να μπορεί να επανέλθει στο ίδιο σημείο. Η αποθήκευση καθαρίζεται όταν ο χρήστης τερματίσει το quiz ή επιστρέψει συνειδητά στην αρχική οθόνη του quiz.

Αν κατά την τοπική ανάπτυξη φαίνεται ότι ολόκληρη η εφαρμογή “επανεκκινεί”, ελέγξτε αν τρέχει μέσω εργαλείου τύπου Live Server με auto reload. Για πιο σταθερή δοκιμή πριν από GitHub Pages προτείνεται απλός στατικός server:

```bash
cd AE007
python3 -m http.server 8766 --bind 127.0.0.1
```

Μετά ανοίξτε `http://127.0.0.1:8766/`.

## Τοπική εκτέλεση / GitHub Pages

Ανοίγετε μέσω **HTTP**, όχι `file://` (φόρτωση JSON / θεωρίας):

```bash
cd AE007 && npx --yes serve .
# ή Python: python3 -m http.server 8080
```

Για **GitHub Pages**: ανεβάστε τα **περιεχόμενα** του φακέλου `AE007/` ως ρίζα ιστοτόπου (ή σε `/docs`), ώστε `index.html` να είναι στην κορυφή.

Αν η δημοσίευση μετατοπίσει βάση URL (όχι ρίζα), τα σχετικά διαδρομές `fetch(...)` μέσα στο `index.html` ενδέχεται να χρειάζονται ρύθμιση (σήμερα: `questions_bank.json`, `theoria/theory.json`, `insurance_agent_yli/`).

### GitHub Pages ως υποδιαδρομή (`https://χρήστης.github.io/repo/`)

Για υποχρεωτική βάση URL, μέσα στο `<head>` του **ριζικού** `index.html` (πριν από το rebuild) ή με μικρή μετα-επεξεργασία στο `AE007/index.html`:

```html
<base href="/όνομα-repo/">
```

Προσαρμόστε το path ώστε να τελειώνει με `/`. Αν το site εξυπηρετείται από ρίζα domain, **αφαιρέστε** ή μην βάλετε `<base>` (αλλιώς μπορεί να σπάσουν τα σχετικά URLs).
